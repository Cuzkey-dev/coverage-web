# 動くモデルのデザイン

2026-09-24。学習用のインタラクティブな解説を参考に、学会発表で図を見比べやすい外観へ調整。

| 参考 | 採用した考え方 |
| --- | --- |
| [Seeing Theory](https://seeing-theory.brown.edu/) | 図を中心に据え、モデルの選択肢を短い見出しと図で示す。 |
| [Bartosz Ciechanowski: Mechanical Watch](https://ciechanow.ski/mechanical-watch/) | 図と操作部を近づけ、説明は余白と読みやすい幅を確保する。 |
| [Red Blob Games](https://www.redblobgames.com/) | 具体的な入力例から入り、図を操作した後に仕組みを読める構成。 |

参考サイトのコード・画像は使用しない。独自の配色、SVGアイコン、余白、見出しを実装。生成り色の背景、白い図版、青緑の操作部を使う。3段階の図とロボットの凡例を同じ面にまとめ、スマートフォンでは縦に並べる。キーボードフォーカスと動きの抑制設定にも対応。

鳥は横向きの滑らかな輪郭。翼先の大きな上下動に手首の遅れ、折りたたみ、胴体の上下動と傾きを加えた表現で、生物学的な飛行モデルではない。顔はまばたきと眉・口元の左右差を加える。いずれも入力画像自体を処理し、輪郭とロボットの結果を再生成する。

制御には先取り入力を使わない。標準2倍速、開始時からの入力変化、ロボットの単色表示を継続する。
