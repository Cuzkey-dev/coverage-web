# Coverage Web

画像の輪郭を、ロボット群の配置で表現するシミュレーションアプリです。ロボットが移動して形をつくる様子をブラウザで再生し、台数や初期配置によって結果がどう変わるかを比較できます。

**[アプリを試す](https://coverage-web-tau.vercel.app/new)** · **[保存済みの作例を見る](https://coverage-web-tau.vercel.app/runs/cmtsxaeyh000004jryhrsjdd6)**

## 使い方

1. サンプル画像を選ぶか、自分の画像をアップロードします。
2. ロボットの台数や初期配置を設定して、シミュレーションを実行します。最初は既定の120台・全域ランダム配置で試せます。
3. 配置と移動軌跡を再生し、画像の輪郭をどの程度表現できたかを確認します。
4. 条件を変えて比較し、必要に応じて図やデータを書き出します。結果を共有したい場合は「公開保存」を利用できます。

## できること

| 機能 | 内容 |
| --- | --- |
| 画像からのシミュレーション | 鳥・蝶・星・街並み・リング・葉の6種類のサンプルと、画像アップロードに対応 |
| 条件の設定 | 最大1,200台・3,000ステップ。全域ランダム、左下、左半分、外周、格子、輪郭近くの6種類の初期配置 |
| 結果の比較 | 台数または初期配置を変えた4条件の一括実行と、保存済みの結果2件の比較 |
| 再生と評価 | 配置・移動軌跡の再生に加え、F1スコア、輪郭充足率、平均輪郭距離、輪郭誤差を表示 |
| 書き出しと共有 | 配置図・比較図のPNG、評価値・座標のCSV、結果のJSON出力と公開保存 |

評価値は、同じ画像・解像度・計算モデルで条件を比較するときの目安として利用できます。見た目の再現度は、配置図や再生結果と合わせて確認してください。本アプリはシミュレーション用で、実機の動作や安全性を検証するものではありません。

## 画像と保存データについて

入力画像は長辺512画素以下のグレースケール画像に変換され、計算サーバーへ送信されます。シミュレーションの実行だけでは、結果はデータベースに保存されません。

「公開保存」を選ぶと、画像の参照輪郭、ファイル名、実行条件、ロボットの座標、評価値が保存され、誰でも閲覧できるようになります。公開してよい画像・ファイル名で利用してください。保存した結果は、同じブラウザから削除できます。

保存件数には上限があり、古い結果は整理されることがあります。手元に残したい結果は、JSONやCSVでも書き出してください。

## 開発について

Next.js 16、React 19、TypeScript、Tailwind CSS、Prisma 7、Neon PostgreSQLを使用し、Vercelで公開しています。

このリポジトリには、Web画面、結果の保存・比較機能、計算サービスとの連携を含みます。計算エンジンは別途管理しており、このリポジトリには含まれません。ローカルで新規シミュレーションを実行するには、計算サービスへの接続設定が必要です。

環境構築、データ形式、運用の詳細は[開発・運用ガイド](docs/development.md)を参照してください。
