# Coverage Web

画像から重要度関数 Φ を設計し、二輪移動ロボットの**被覆制御シミュレーション**を実行・保存・比較できる Web アプリケーションです。

修士研究（東京都立大学 児島研究室・ロボットマスゲームにおける被覆制御）で使っている MATLAB のシミュレーションを、
**ブラウザ上で誰でもパラメータを変えて試せるツール**として作り直しています。

## なぜ作るか

被覆制御では、環境のどこを重視するかを表す重要度関数 Φ の設計が結果を大きく左右します。
しかし Φ を変えるたびにスクリプトを書き換えて実行し直す必要があり、
**条件を変えた実行どうしを見比べる**のに手間がかかっていました。

このツールでは次を目指しています。

- 画像をアップロードし、エッジ検出のパラメータを触りながら Φ をその場で作る
- その Φ でシミュレーションを実行し、結果を保存する
- 過去の実行と並べ、パラメータの差分と評価値を対比する

## 機能

- [x] シミュレーションのコア（Voronoi 分割・重み付き重心・Lloyd 法）
- [ ] ブラウザ上での描画
- [ ] 認証
- [ ] 実行結果の保存・一覧
- [ ] 画像からの Φ 生成（Canny / Sobel / Scharr）
- [ ] 実行どうしの比較、共有 URL

## 設計メモ

- **シミュレーションのコアは純粋関数に切り出す**（`src/lib/coverage/`）。
  React や DB に依存させないことで、そのままユニットテストの対象にできる。
- **距離比較には平方根を使わない**。順序さえ保てればよく、格子の全セルを走査するため効果が大きい。
- **担当セルを持たないロボットは動かさない**。移動させる根拠がないため、現在地を保持する。
- **実行結果は当面 JSON カラムで持つ**。何を保存すべきかが固まっていない段階で
  正規化するとスキーマ変更が頻発するため、確定してからテーブルに分ける。

## 開発

```bash
npm install
cp .env.example .env   # DATABASE_URL を設定する
npm run db:push        # スキーマをデータベースへ反映
npm run dev
```

| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm test` | テスト実行 |
| `npm run typecheck` | 型検査 |
| `npm run lint` | Lint |
