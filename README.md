# Coverage Web

画像から重要度関数Φを設計し、点ロボットの配置をLloyd法で計算・保存・比較するWebアプリ。

[公開アプリ](https://coverage-web-tau.vercel.app/new)

## できること

- 最大 **1,200台・3,000ステップ・256×256セル**。既定は120台、最大600ステップ、128×128セル。
- 鳥・蝶・星・街並み・リング・葉の6サンプル。独自に生成した図形で、画像素材は不要。
- 画像アップロード、ドラッグ＆ドロップ、透明背景の白合成。処理用画像は長辺512画素へ縮小。
- Sobel / Scharr / Canny、入力のぼかし、輪郭帯のぼかし、背景の重み、解像度を調整。
- 初期配置は「輪郭近くに分散」「全域ランダム」「左下」「左半分」「外周」「格子」の6種類。
- 120・300・600・1,200台、または4種類の初期配置を同じ画像・Φ・解像度・シードで一括比較。
- 白地の配置図、軌跡とΦの表示切替、再生、評価値Hと輪郭充足率の推移。
- 配置図・比較図PNG、評価値・最終座標・比較表CSV、条件と結果JSONをダウンロード。
- 公開保存、保存した結果の再生、2件の比較。同じブラウザから保存した結果の削除。

## モデルと評価の範囲

公開版は、各点を重み付きVoronoi領域の重心へ移す**点ロボットのLloyd法**です。
二輪ロボットの運動学、実機の速度制約、衝突回避、非公開研究の独自手法は含みません。
画像処理・乱数・離散化が異なる他のシミュレータとの数値一致を保証するものではありません。

Φは `floor + (1-floor) × 正規化したエッジ帯`。
エッジを格子へ面積平均した後、任意のGaussianぼかしで帯幅を調整します。
既定は背景重み0、帯のσ=1セル。「輪郭近くに分散」はΦに比例した確率で初期位置を選びます。
全域や隅から始めた場合、重みのない領域を担当する点は現在位置に留まることがあります。
初期配置を比較して、この違いも確認できます。

- **H**: `Σq min_i ||q-p_i||² Φ(q)`。同じΦ・解像度内で比較します。
- **輪郭充足率**: 半径3セル以内に1台以上いる輪郭セルの割合。
- **平均輪郭距離**: 各点から最寄り輪郭セルまでの距離の平均（セル単位）。
- 輪郭セルは、ぼかしによる帯の拡大前の検出エッジを面積平均し、正の値を持つセルと定義。
- 輪郭指標は10ステップごとと最終時点を計測。研究用F1や物理的な安全性の評価ではありません。
- 座標はセル中心が整数、xは右向き、yは下向き。PNGの点の大きさは視認用で実機半径ではありません。
- 最大移動量が0.001セル未満で5回続くと停止（最低10ステップ）。実際の終了ステップを保存します。

## 実装

Next.js 16 / React 19 / TypeScript / Tailwind CSS / Prisma 7 / Neon PostgreSQL / Vercel。

- `src/lib/coverage/spatial.ts`: exact kd-tree。総当たりとの等価性・同距離時の添字順をテスト。
- `experiment.ts`: 初期配置、Voronoi割当とHの同時計算、幾何指標、収束停止。
- `experiment.worker.ts`: Web Worker内で計算。中止時はWorkerを終了し、UIを応答可能に保つ。
- `phi.ts`: 画像処理。`samples.ts`: 独自サンプル。旧seed用画像は`sampleImage.ts`。
- `runResult.ts`: バージョン1の既存結果を維持し、任意の設定・品質指標を追加。
- 新規実行の位置履歴は台数に応じて12〜121枚へ段階的に間引く。先頭と最終を保持。Hは全ステップ保存。
- 保存時に格子サイズ・数値・フレーム・台数・ステップの整合性を検証。結果上限1.8MB、Server Action上限2MB。

| --- | --- |

## 公開保存

元画像ファイルはサーバーに送りません。保存されるΦ・ファイル名・条件・座標・評価値は誰でも閲覧できます。
**Φから元の輪郭を読み取れるため、公開できる画像だけを保存してください。**
認証は未実装。同じブラウザの所有者トークンを使って削除を制限していますが、本人認証ではありません。
保存上限は200件で、超過時は古い訪問者の結果から整理します。seedのお手本2件は整理対象外です。

## 開発と検証

```bash
npm install
cp .env.example .env
# DATABASE_URLを設定
npm run db:local  # 必要な場合のみ、開発用PostgreSQLを起動
npm run db:push
npm run dev
```

```bash
npm run typecheck
npm run lint
npm test
npm run build
npx tsx scripts/benchmark.ts <出力ディレクトリ>
```

ベンチマークは6画像の120台と、鳥の300/600/1,200台を計測し、時間・輪郭指標・保存量・結果JSONを出力します。
実測時間はCPU・ブラウザ・画像・条件で変わります。CIは型検査、lint、テスト、本番ビルドを実行します。

## Vercel + Neon

既存のGitHub連携からmainの更新を自動デプロイします。`DATABASE_URL`にはNeonのプール接続を設定します。
スキーマを変更した場合のみ`npm run db:push`。`npm run db:seed`は初回のお手本投入用です。
`/api/health`でアプリとDBの応答を確認できます。秘密情報は環境変数で管理し、Gitに入れません。
