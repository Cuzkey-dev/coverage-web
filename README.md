# Coverage Web

画像をロボット群で表現し、配置を計算・再生・保存・比較するWebアプリ。
[公開アプリ](https://coverage-web-tau.vercel.app/new)

## 機能

- 最大1,200台・3,000ステップ。既定は120台・3,000ステップ・全域ランダム・シード7。
- 鳥・蝶・星・街並み・リング・葉の6サンプルと画像アップロード。
- 全域ランダム、左下、左半分、外周、格子、輪郭近くの6種類の初期配置。
- 台数4条件または初期配置4条件の一括比較。
- 配置と軌跡の再生、F1・輪郭充足率・平均輪郭距離・輪郭誤差の評価。
- 配置図と比較図PNG、評価値と座標CSV、結果JSONの出力。
- 公開保存と2件の比較。同じブラウザで保存した結果の削除。

## 計算とデータ

新規実行はサーバーの研究モデルを使用します。計算エンジンのソース・数式・制御パラメータ・内部の重要度分布は、この公開リポジトリにもブラウザへの応答にも含みません。

画像は長辺512画素以下のグレースケールへ変換し、計算サーバーへ送信します。計算だけではDBへ保存しません。「公開保存」では参照輪郭、ファイル名、公開実行条件、座標、評価値を保存し、誰でも閲覧できるようになります。公開できる画像だけを保存してください。

表示する参照輪郭は入力画像から得た輪郭です。制御に使う内部の重要度分布とは別のデータです。
F1などの品質値は同じ画像・解像度・モデルで比較してください。画像処理の実装が異なるため、MATLABとの全結果の数値一致を保証するものではありません。実機の安全性を保証するツールではありません。

結果には採用した配置のステップと、実際に計算したステップを別々に記録します。再生は採用時点までです。処理時間の上限に達した場合は明示し、得られた結果を返します。
座標はセル中心が整数、xは右向き、yは下向きです。描画の点の大きさは実機半径ではありません。

旧Lloydモデルの保存結果も再生できます。旧モデルのHと新モデルの輪郭誤差は別の指標として扱い、差分を表示しません。

## 構成

Next.js 16 / React 19 / TypeScript / Tailwind CSS / Prisma 7 / Neon PostgreSQL / Vercel。

- `src/app/api/simulate/route.ts`: サーバー間認証とストリーム中継。応答は公開項目だけに制限。
- `src/lib/coverage/serverExperiment.ts`: グレースケール変換、実行要求、進捗受信、中止。
- `src/lib/coverage/runResult.ts`: 保存データ検証。既存のバージョン1結果に対応。
- `samples.ts`: 独自サンプル。`experiment.ts`、`phi.ts`、`experiment.worker.ts`は旧一般モデルと互換処理。
- 履歴は台数に応じて間引き、先頭と採用時点を保持。保存結果の上限1.8MB。

計算サービスが未設定または停止中の場合はエラーを表示します。旧モデルへの自動切替は行いません。

## 開発

```bash
npm install
cp .env.example .env
# DATABASE_URL、COVERAGE_ENGINE_URL、COVERAGE_ENGINE_TOKENを設定
npm run dev
```

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

`npm run db:local`は開発用PostgreSQLの起動用。`db:push`はスキーマ変更時のみ、`db:seed`は初回のお手本投入用です。既存DBに対して再投入しないでください。
`scripts/benchmark.ts`は旧一般モデルのベンチマークです。

## 運用

公開フロントエンドはGitHub mainからVercelへ自動デプロイ。計算エンジンは非公開の別プロジェクトとして管理します。
環境変数`COVERAGE_ENGINE_URL`と`COVERAGE_ENGINE_TOKEN`はサーバー専用で、`NEXT_PUBLIC_`を付けません。
`DATABASE_URL`にはNeonのプール接続を設定します。秘密値をGitやログに書かないでください。

`/api/health`でアプリとDBの応答を確認できます。保存上限は200件で、超過時は古い訪問者の結果から整理します。初回のお手本は整理対象外です。
削除制限にはブラウザの所有者トークンを使用しており、本人認証は未実装です。
